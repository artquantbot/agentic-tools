# Product strategy

Agentic Tools turns a task into a shortlist that humans and agents can inspect through the same decision engine. It joins project identity, publisher declarations and curated capability evidence across frameworks, runtimes, infrastructure and MCP servers. Each recommendation shows which requirements have supporting evidence and which still need verification. Mandatory constraints govern eligibility and GitHub popularity remains a separate sort. This gives builders a way to compare across categories, assess the limits of the evidence and reach the original setup documentation.

Initial scope is transparent discovery, filtering, comparison and stack shortlisting. No account or paid model is needed. Success measures include top-three relevance, constraint violations, freshness, import failure rates and time to the first usable shortlist. Runtime or compatibility certification requires separately recorded tests.
