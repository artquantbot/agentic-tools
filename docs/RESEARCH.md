# Research

Retrieved 2026-11-21 UTC. Registry formats and availability can change.

- [Official MCP Registry aggregator guide](https://modelcontextprotocol.io/registry/registry-aggregators) documents public cursor-based JSON, incremental updates and deletion markers. [Registry FAQ](https://modelcontextprotocol.io/registry/faq) calls the service a preview. [Registry implementation](https://github.com/modelcontextprotocol/registry/blob/main/LICENSE) is Apache-2.0. The importer can collect publisher-supplied identities as leads for review. Public catalog records use GitHub identity and reviewed upstream documentation.
- [GitHub search](https://docs.github.com/en/rest/search/search) caps results at 1,000 per query and applies search-specific rate limits. [Repository metadata](https://docs.github.com/en/rest/repos/repos#get-a-repository) supplies repository IDs, SPDX labels, archive state, activity and stars. Cache conditional results and keep source timestamps.
- [OpenAI Agents SDK](https://openai.github.io/openai-agents-python/) provides agent composition and handoffs. [LangGraph](https://docs.langchain.com/oss/python/langgraph/overview) provides durable graph execution, distinct from the higher-level [LangChain framework](https://docs.langchain.com/oss/python/langchain/overview). [CrewAI](https://docs.crewai.com/) offers crews and flows. [MCP](https://modelcontextprotocol.io/specification/2026-07-28/basic/transports) defines tool exposure and transports. The [official SDK release](https://github.com/modelcontextprotocol/typescript-sdk/releases) provides the current web-standard HTTP transport in the split 2.4.0 server/client packages.
- [Docker Sandboxes](https://docs.docker.com/ai/sandboxes/) isolates coding workflows. [Cloudflare Agents](https://developers.cloudflare.com/agents/) provides stateful agent primitives on Workers. [E2B](https://docs.e2b.dev/) and [Daytona](https://www.daytona.io/docs/) offer programmable code environments. [Browserbase](https://docs.browserbase.com/welcome/introduction) offers hosted browsers. These roles are distinct from Python/Node browser control and local model inference.
- [Ollama](https://docs.ollama.com/) runs models locally, [llama.cpp](https://github.com/ggml-org/llama.cpp) provides native inference, [MLX](https://github.com/ml-explore/mlx) targets Apple Silicon, and the [Hugging Face Hub API](https://huggingface.co/docs/hub/api) covers model/dataset/Space metadata. Model licenses and hardware requirements vary independently of runner licenses.
- [OWASP Agentic Top 10](https://genai.owasp.org/resource/owasp-top-10-for-agentic-applications-for-2026/) covers goal hijacking, tool misuse, and supply-chain risks. [MCP security guidance](https://modelcontextprotocol.io/specification/2025-11-25/basic/security_best_practices) addresses request validation and network boundaries. [GitHub Advisories](https://docs.github.com/en/rest/security-advisories/global-advisories) needs ecosystem/package/version joins. [CISA KEV mirror](https://github.com/cisagov/kev-data) provides CVE evidence of exploitation and requires exact product/version matching. [SLSA](https://slsa.dev/spec/) informs build and release provenance. Absent advisory data is classified as unknown.
- npm registry version checks returned Next 16.4.6, React 19.3.1, TypeScript 7.0.2, Vite 8.3.8 and Zod 4.6.7. [Workers Static Assets](https://developers.cloudflare.com/workers/static-assets/) supports SPA fallbacks and deterministic API routing. [Cloudflare Vite plugin v2](https://developers.cloudflare.com/workers/vite-plugin/v2-beta/) uses programmatic configuration and the [cf CLI](https://developers.cloudflare.com/cf/projects/). [Vercel Hobby](https://vercel.com/docs/plans/hobby) targets non-commercial usage. [Supabase pricing](https://supabase.com/pricing) and [D1 pricing](https://developers.cloudflare.com/workers/platform/pricing/#d1) were evaluated for mutable storage.

Public DNS returned NXDOMAIN for the target hostname. The parent zone delegates to Cloudflare. Delegation alone does not establish account authorization.
