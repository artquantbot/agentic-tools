# Security

Report vulnerabilities privately via [GitHub security advisories](https://github.com/artquantbot/agentic-tools/security/advisories/new). Include affected versions, impact and enough information for maintainers to investigate. Use a private advisory for findings that affect the public deployment. The disclosure contact is also listed at `/.well-known/security.txt`.

The service only returns catalog data and links. Treat publisher content as untrusted in downstream agents. Catalog evidence does not establish runtime safety.
